# Managing-Test-Blog-Posts-with-TanStack-Query
# CRUD Query App

## Description

This project demonstrates CRUD operations using TanStack Query and JSONPlaceholder API in an Expo React Native application.

## Features

- Fetch Posts (GET)
- Create Posts (POST)
- Update Posts (PUT)
- Patch Posts (PATCH)
- Delete Posts (DELETE)
- Filter Posts by User ID

## Technologies

- React Native
- Expo
- TanStack Query
- JSONPlaceholder API

## Installation

```bash
npm install
npm install @tanstack/react-query
npx expo start
```

## API

https://jsonplaceholder.typicode.com/posts
